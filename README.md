# Triplast · Sitio web

Proyecto web desarrollado con HTML, CSS y JavaScript, organizado para trabajar en Visual Studio Code.

## Ejecutar en el computador

1. Abrir la carpeta `Triplast_Web_Editable` en Visual Studio Code.
2. Abrir una terminal y ejecutar `python run.py`.
3. Visitar `http://localhost:8000`.

## Archivos principales

- `index.html`: estructura de la página.
- `css/`: estilos y diseño adaptable.
- `js/`: funciones e interacciones.
- `assets/img/`: fotografías, imágenes y logotipo.
- `data/`: contenido editable de noticias y galería.
- `run.py`: inicio del servidor local.

## Actualizar contenido

Las noticias se administran en `data/noticias.json` y las fotografías de la galería en `data/galeria.json`. Los archivos de imagen se guardan en `assets/img/`.

Después de realizar cambios, guardar los archivos y subirlos al repositorio de GitHub para actualizar el sitio publicado.

## Publicación en GitHub Pages

Subir el contenido de la carpeta al repositorio, con `index.html` en la raíz. En **Settings → Pages**, seleccionar la rama `main` y la carpeta `/ (root)` para publicar.
