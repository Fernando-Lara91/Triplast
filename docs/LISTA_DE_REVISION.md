# Revisión antes de publicar
- [ ] Fotos propias disponibles, optimizadas y con derechos de publicación.
- [ ] Nombres, cargos, antecedentes y logros ratificados por el equipo.
- [ ] Contacto comercial oficial verificado.
- [ ] Tasas de PET, botellas y emisiones documentadas con unidades y fuentes (si se activan).
- [ ] Noticias verificadas: enlaces, fechas, fotografías y redacción.
- [ ] Menú móvil y navegación revisados en teléfono y escritorio.
- [ ] Pruebas locales y prueba después de subir a GitHub Pages.
- [ ] Dominio y HTTPS correctamente configurados.
- [ ] Aviso de privacidad agregado si luego se recogen datos personales.
